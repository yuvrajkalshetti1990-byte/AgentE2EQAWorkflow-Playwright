## 2. Removed Tests — Root Cause

### TC-PIM-HP-01 & TC-PIM-NEG-04 — Strict Mode Locator Violation

| Item | Detail |
|---|---|
| Files | `orangehrm-tc-pim-hp-01-add-employee-required-fields.spec.ts` |
| | `orangehrm-tc-pim-neg-04-add-employee-duplicate-id.spec.ts` |
| Error | `strict mode violation: locator resolved to 4 elements` |
| Selector Used | `.oxd-form-row` filtered by label `Employee Id` → `.oxd-input` |
| Root Cause | The `.oxd-form-row` container for the name fields shares the same structure as the Employee Id row; filtering by label text matched all 4 inputs in the form rather than the single Employee Id input |
| Fix Required | Use `page.getByRole('textbox').nth(4)` or a more specific selector targeting only the Employee Id input (e.g. `input.oxd-input:not([name])` or a `data-*` attribute if available) |
